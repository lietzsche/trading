# 스킬 메이커 (Skill Maker)

저장소 루트 기준 `skills/skill-maker/SKILL.md`를 읽고 그 지침에 따라 스킬을 설계·작성·수정한다. 해당 파일이 공통 스킬의 원본이며, 현재 호출에 전달된 대상과 요구사항을 입력으로 사용한다.
