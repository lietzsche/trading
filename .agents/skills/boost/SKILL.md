# 심층 추론 (Boost)

저장소 루트 기준 `skills/boost/SKILL.md`를 읽고 그 지침에 따라 3단계 심층 추론을 수행한다. 해당 파일이 공통 스킬의 원본이며, 현재 호출에 전달된 과제와 대화 맥락을 입력으로 사용한다.
