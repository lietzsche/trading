# CLI 명령어 HTML 설명서

저장소 루트 기준 `skills/cli-guide/SKILL.md`를 읽고 그 지침에 따라 설명서를 만든다. 해당 파일이 공통 스킬의 원본이며, 양식은 `skills/cli-guide/assets/example.html`을 따른다. 현재 호출에 전달된 대상과 범위를 입력으로 사용한다.
