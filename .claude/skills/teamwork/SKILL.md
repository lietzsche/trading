# 멀티에이전트 팀 협업 (Teamwork)

저장소 루트 기준 `skills/teamwork/SKILL.md`를 읽고 그 지침에 따라 4단계 팀 협업 워크플로를 수행한다. 해당 파일이 공통 스킬의 원본이며, 현재 호출에 전달된 프로젝트 목표와 범위를 입력으로 사용한다.
