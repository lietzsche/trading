# AI 대화 삭제 개선 검수

## 변경

- 단건 삭제 시 분석 및 후속 메시지의 PENDING/RUNNING 상태를 같은 트랜잭션에서 검사한다.
- 후속 메시지 등록도 분석 행을 잠가 삭제와 등록이 동시에 실행되는 경우를 보호한다.
- 관리자 전용 일괄 삭제는 최대 50개를 받아 본인 소유의 표시된 기록만 처리한다. 진행 중 항목은 건너뛰고 적용된 기록은 숨겨 보존한다.
- 목록에 후속 메시지 진행 플래그, 페이지 단위 선택, 삭제/숨김 개수, 자동 판단 필터를 제공한다.
- 삭제로 페이지가 비면 이전 페이지를 조회하고, 삭제된 상세 패널은 초기화한다.
- AI에서 다른 탭으로 이동할 때 공통 탐색 함수를 사용한다.
- API 공개 포트를 127.0.0.1:8001로 제한한다.

## 검수

- API pytest 152개, 프런트 Vitest 19개 및 프로덕션 빌드 통과.
- Chromium 375×812, 모의 API로 3개 선택 및 혼합 삭제/숨김/진행 중 건너뛰기, 총 개수 갱신, 빈 마지막 페이지 이동 확인.
- 모바일 선택 목록 세로 정렬과 가로 넘침 없음, 삭제 바와 mobile-nav 사이 간격 확인.
- 실제 DB 목록 및 자동 판단 필터 쿼리 읽기 전용 검증.
- ./reup.sh 완료, 고정 도메인 /api/health에서 API·DB·계산 서비스 UP 확인.
- 호스트 리스너 127.0.0.1:8001만 존재, 서버 LAN IP 192.168.0.177:8001 연결 거부 확인. 별도 외부 기기에서의 접속 검수는 수행하지 않았다.
- 운영 대화는 검수 과정에서 삭제하지 않았다.
