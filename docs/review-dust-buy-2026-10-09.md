# 작업 14 — 소액 보유 코인의 신규 매수 허용

## 변경

`_auto_order_for_key` action 루프의 `excluded` 통화 일괄 건너뛰기 조건만 제거했다. 소액·미지원 잔고를 계산 입력의 balances에서 제외하는 작업 13 규칙은 유지한다. 매수 추천 순서, 최소 주문 금액, 계정 권한 확인, 미확인 주문 차단 규칙은 변경하지 않았다.

소액 잔고 때문에 매도할 수 없는 통화라도 현재 추천에 포함돼 있으면 신규 매수할 수 있다. 미지원 마켓의 주문 실패 처리와 추천 목록 정리 등 기존 보호는 그대로 유지한다.

## 테스트

- 추가: `test_dust_btc_still_buys_first_recommended_btc` 통과.
  - BTC 0.001 × 현재가 10,000원 = 10원으로 최소 주문 금액 5,000원 미만.
  - balances에는 KRW만 전달하고 추천 `[KRW-BTC, KRW-ETH, KRW-SOL]`은 그대로 유지.
  - 첫 BUY가 KRW-BTC이며, 기존 수수료 반영 금액 9,995원으로 주문.
  - 모의 주문 후 원화 잔고 소진을 반영해 추가 주문이 없는 것도 확인.
- 기존 테스트 변경 없음. 일괄 건너뛰기 조건 자체에 의존하는 기존 테스트는 없었다.
- 전체 pytest: **261개 통과**, 기존 Starlette deprecation 경고 1개.
- Docker `--network none` + 모의 DB·모의 주문만 사용. 운영 DB 변경이나 실제 주문 테스트 없음.
- 프런트엔드 및 계산 서비스 코드 변경 없음.

## 배포

배포 전 AI 분석·후속 메시지 상태를 SELECT로 확인해 진행 중인 작업이 없음을 확인했다. 배포 결과는 확인 후 기록한다.
