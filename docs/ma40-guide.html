Upbit MA40 Auto Trader — 전략 흐름 및 데이터 구조 가이드

1. 전체 설정 기반 5분 신호 수집 및 30초 자동 주문·안전 차단 흐름

설정 탭에서 지정한 전체 기준 일봉 수(기본 MA40)를 바탕으로 5분마다 신호를 갱신하고 30초마다 주문을 판단합니다. 주문 접수 응답을 확인할 수 없으면 같은 주문을 재전송하지 않고 자동 주문을 차단한 채 Upbit에서 식별자로 재확인합니다.

2. 화면 탭·워커별 저장소 및 외부 API 매핑

모니터링 탭(추천 종목별 원클릭 백테스트 포함), 설정 탭(전체 공통 전략·백테스트 설정)과 2개의 백그라운드 워커가 참조·갱신하는 테이블 및 외부 API 매핑입니다.
