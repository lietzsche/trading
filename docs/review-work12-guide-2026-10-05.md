## 상태

- 1·2 주문 자동 재확인/홈 재확인 버튼: 미반영. 이전 안전 검토가 향후 운영 PENDING/UNKNOWN 상태 갱신을 운영 데이터 변경 금지와 충돌하는 것으로 판단해 코드 추가를 차단했다. 운영 적용 시 조회 결과에 따른 ACCEPTED/REJECTED 갱신이 허용되는지 명시적 확인이 필요하다. 운영 조회·갱신·배포·주문은 실행하지 않았다.
- 3 선택 항목 사용 안내: 완료. 더보기/데스크톱 메뉴, 정적 접이식 6개 섹션, 일반 사용자 접근 지원, AI 첫 방문 카드에 안내 링크. 키가 등록돼 있어도 첫 방문 안내를 표시하며 실제 표시 시 localStorage에 기록한다(try/catch). 모바일 대화 공간 보호를 위해 compact chat에서는 카드가 아닌 요약 보기에서 노출한다.

## 문구 검토

실제 코드에서 추천 최소 3개, 수동 매도 후 10분 제외, 정기 판단 간격 60~1,440분, 자동 설정 검증 20일/청산 3회/낙폭 2%p, 기본 적용 대기 72시간(환경변수 변경 가능), 로그인 IP 5회/아이디 20회, 백업 14개를 확인했다.

현재 미구현인 AI 직접 주문이나 자동 재확인 버튼이 구현된 것처럼 안내하지 않는다. 자동매매가 켜져 있어도 AI 매도 의견 자체는 현재 주문을 실행하지 않는다.
