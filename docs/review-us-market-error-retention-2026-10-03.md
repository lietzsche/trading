# 미국 주식·배당 및 오류 보존 정책 검수

## 적용 범위

- 주식 추천과 배당 화면에 국내/미국 필터, 미국 종목 USD 표시를 추가했다. 기존 추천 순위와 계산 설정은 유지한다.
- 미국 전체 상장 종목이 아닌 기본 40개 주식·ETF 관심 목록이다. `US_STOCK_SYMBOLS`로 최대 100개까지 지정한다. 전략 조건을 만족하지 않으면 추천은 비어 있을 수 있다.
- AI 분석은 `US:AAPL` 또는 `AAPL`을 입력해 미국 일봉을 조회할 수 있다. 백테스트에서는 뉴욕 기준 당일 일봉을 제외한다.
- 미국 증권 계좌 연결·주문 실행·원화 환산은 추가하지 않았다. 국내/미국 주식은 기존 주식 계산 설정을 공유한다.
- 미국 배당률은 최근 365일 기록된 배당 이벤트 금액 합계 / 최근 종가다. 미래 배당·지급일을 예측하지 않으며, 기간 내 분할이 있으면 표시에서 제외한다. 국내 배당 데이터와 산정 기준이 다를 수 있다.
- Yahoo 공개 차트 데이터는 실시간 체결 시세나 가용성을 보장하지 않는다. 5분 캐시, 요청 간격 및 429 발생 시 10분 대기를 적용했다. 데이터 구조 참고: [yfinance 공식 소스](https://github.com/ranaroussi/yfinance/blob/main/yfinance/scrapers/history.py).

## 오류 보존

- 기본 30일, 최대 10,000건. 시작 시 및 매시간 `trade_error_log`만 한 트랜잭션으로 정리한다. 정리 사이에는 일시적으로 최대 건수를 넘을 수 있다.
- `ERROR_LOG_RETENTION_DAYS`, `ERROR_LOG_MAX_RECORDS`로 조절한다. 거래·주문·추천·AI 분석 기록은 삭제하지 않는다.
- V009는 조회 인덱스만 추가한다. Docker 로그는 컨테이너별 10MB × 3개로 제한한다.
- 운영 DB 설정과 기록을 수정하거나 삭제하지 않았으며 재배포도 실행하지 않았다. 다음 `./reup.sh`부터 기존 오류에도 삭제 정책이 적용된다. 필요한 오류는 먼저 백업해야 한다.

## 검수 결과

- 운영 네트워크와 분리한 테스트 이미지: pytest **178 통과**, 기존 Starlette 경고 1건.
- Vitest **28 통과 / 4 파일**, 프로덕션 빌드 통과. Compose 설정 검증 통과.
- UI 자동 감사 **21/21 통과**, 하드코딩 색상 0, 라이트·다크 대비 검사 통과.
- 모의 API Playwright: 375×812 라이트·다크에서 국내/미국 필터, 달러/원 표시, 미국 배당 및 보존 안내 확인. 가로 넘침과 브라우저 런타임 오류 없음. 계좌·거래·AI 유료 호출 없이 실행했다.
- 미국 공개 API 읽기 전용 조회: AAPL·KO 각각 일봉 251개, 배당 이벤트 확인. 유료 AI 키는 사용하지 않았다.
- 운영과 별도인 네트워크 없는 임시 PostgreSQL: V009 두 번 적용으로 멱등성 확인. 모의 오류 170건 중 30일 초과 20건, 최대 100건 초과 50건 삭제 후 최신 100건(id 71~170) 유지 확인. 운영 오류는 삭제하지 않았다.
- 신규 테스트: 미국 일봉/통화/완료일 검증, 배당 및 분할 제외, 캐시·429 대기, 관심 목록 범위, AI 티커·미국 이력, 오류 보존 트랜잭션, 추천 수집, 뉴욕 시간 스케줄.
