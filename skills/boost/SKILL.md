# 심층 추론 (Boost)

단순한 일차 시도로 풀기 어려운 버그, 경쟁 상태(race condition), 성능·알고리즘 최적화, 복잡한 아키텍처 문제를 3단계 멀티 관점 추론으로 해결한다. 사용자의 언어로 대화한다.

## 입력과 시작하기

- 호출에 전달된 과제, 오류 메시지, 재현 조건, 기존 대화를 먼저 읽는다.
- 저장소 구조, 관련 코드, 설정, 사용 가능한 테스트·빌드 명령 등 직접 조사해 알 수 있는 사실은 먼저 확인하고 사용자에게 다시 묻지 않는다.
- 목표나 제약이 불분명해 해결 방향이 크게 갈리는 경우에만 한 번에 한 질문씩 확인한다. 선택형 질문은 `skills/grill-me/SKILL.md`의 선택형 질문 UI 지침을 따른다.
- 사소한 공백은 합리적인 가정으로 기록하고 추론을 시작한다.

## 실행 단계: 3단계 심층 추론 워크플로

첫 번째 추측에 의존해 바로 코드를 수정하지 않고, 다음 3단계를 순서대로 수행한다.

### 1단계 — 전략 수립 및 가설 분해 (Orchestrator)

- 해결해야 할 핵심 문제와 **검증 가능한 완료 기준**(통과해야 할 테스트, 성능 목표, 회귀 방지 조건)을 정의한다.
- 문제를 설명하거나 해결할 수 있는 **경쟁 가설 또는 후보 해법 2~3개**를 도출한다.
  - 디버깅·원인 분석: 가능한 근본 원인 가설 A, B, C와 각 가설이 맞을 때 나타나야 하는 코드·런타임 증거
  - 최적화·설계·구현: 서로 다른 접근법 A, B(예: 시간·공간 복잡도 절충, 구조 변경 범위 비교)
- 각 가설·후보를 어떤 순서와 방법으로 검증할지 조사 계획을 세운다.

### 2단계 — 심층 조사 및 해법 구현 (DeepInvestigator / DeepCoder)

- **DeepInvestigator (다각도 조사)**:
  - 1단계에서 세운 가설별로 실제 코드 경로, 데이터 흐름, 상태 전이, 경계 조건을 추적하거나 최소 재현 실험을 수행한다.
  - 추측이 아니라 확인된 증거를 바탕으로 틀린 가설을 기각하고, 근본 원인 또는 최적의 설계안을 확정한다.
- **DeepCoder (정밀 구현)**:
  - 확정된 해법을 구현한다. 사용자가 분석·조언만 요청한 경우에는 코드를 수정하지 않고 구체적인 패치 설계만 제시한다.
  - 인접 모듈에 미치는 부수 효과를 점검하고, 경계값·예외 처리·동시성 안전성을 함께 반영한다.

### 3단계 — 독립 검증 및 반례 점검 (Independent Verifier)

- 구현자의 시각에서 벗어나 **비판적 검증자** 관점으로 변경 사항을 점검한다.
- 다음 항목을 확인한다:
  - 기존 실패 조건이 실제로 해결되었는지 재현 테스트나 단위·통합 테스트로 입증했는가?
  - 빈 입력, 최대 크기, 동시 호출, 실패 복구 등 반례(edge case)에서 깨지지 않는가?
  - 기존 테스트 스위트, 타입 검사, 린트, 빌드에서 회귀(regression)가 발생하지 않는가?
- 검증 중 결함이나 미해결 케이스가 드러나면 1~2단계로 돌아가 가설과 구현을 수정하고 다시 검증한다.

## 환경별 멀티에이전트·도구 활용

실행 환경이 제공하는 도구에 맞춰 조사와 검증의 독립성을 극대화한다.

- **Claude Code**:
  - 서브에이전트 도구(예: `Task` / `Agent` 도구)를 사용할 수 있으면, 2단계의 가설별 코드 조사와 3단계의 독립 검증을 서브에이전트에 위임한다.
  - 서로 독립적인 가설 조사는 병렬로 실행해 탐색 시간을 줄이고, 3단계 검증 서브에이전트에는 구현 맥락에 편향되지 않도록 "반례와 회귀 가능성을 찾아 테스트로 검증하라"는 지시를 넘긴다.
- **Codex**:
  - 현재 세션에서 서브에이전트·멀티에이전트 도구가 제공되면 가설 조사와 독립 검증을 분리해 위임한다.
  - 두 가지 이상의 구현 후보를 격리해 실험해야 하고 환경이 허용하면 `git worktree` 등을 활용해 비교한 뒤 최종 해법만 반영한다.
- **단일 에이전트 대체 동작 (Fallback)**:
  - 서브에이전트를 생성할 수 없는 모드나 환경에서는 메인 에이전트가 `1. Orchestrator` → `2. DeepInvestigator / DeepCoder` → `3. Independent Verifier` 역할을 순서대로 전환하며 수행한다.
  - 단일 에이전트로 실행하더라도 **복수 가설 수립 → 증거 기반 소거 → 테스트 기반 독립 검증** 절차는 생략하지 않는다.

## 결과물과 마무리

모든 단계와 검증이 끝나면 다음 내용을 간결하게 정리해 대화에 보고한다.

- **핵심 원인 및 최종 해법**: 무엇이 문제였고 어떻게 해결했는지 요약
- **검토한 가설·대안 비교**: 확인한 가설/접근법들과 각각의 채택·기각 근거
- **변경 파일 및 검증 결과**: 생성·수정한 파일 경로와 실제 실행한 테스트·검증 명령 결과
- **가정 및 남은 위험**: 환경 제약으로 직접 실행하지 못한 검증이나 추후 확인할 사항

기존 승인 범위를 넘어서는 위험한 명령이나 권한 우회는 수행하지 않는다. 저장소 내 코드·문서를 수정한 작업 단위가 완료되었고 프로젝트의 커밋·푸시 규칙(`AGENTS.md`)이 적용되는 경우 해당 규칙을 따른다.
