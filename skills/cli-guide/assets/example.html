Antigravity CLI 스킬 정리

Google Antigravity CLI(agy)의 스킬 사용법과 기본 탑재 슬래시 명령을 공식 문서 기준으로 정리했습니다.

조사일: 2026-11-09 · 출처: antigravity.google 공식 문서 · 문서는 수시로 바뀔 수 있습니다.
1. CLI에서 스킬 쓰기 2. 핵심 워크플로 명령 3. 전체 슬래시 명령

1. CLI에서 스킬 쓰기

CLI가 스킬을 읽는 위치, 슬래시 명령 변환, 관리 명령입니다.

위치범위
<workspace>/.agents/skills/<skill>/워크스페이스 전용. 상위 폴더의 .agents/skills/도 저장소 루트까지 탐색. 구버전 .agent/skills 호환
~/.gemini/config/skills/<skill>/전역 (Antigravity App과 공유)
~/.gemini/config/plugins/<plugin>/skills/플러그인이 제공하는 스킬
~/.gemini/antigravity-cli/skills/, ~/.gemini/skills/CLI 전용 (App은 읽지 않음)

스킬 → 슬래시 명령 자동 변환

스킬 deploy-staging을 만들면 TUI에서 /deploy-staging으로 호출할 수 있습니다.

출처: Agent skills (CLI) ↗

/skills

로드된 로컬·전역 스킬을 탐색합니다. 실행 중에 스킬을 추가했다면 /skills reload로 디스크에서 다시 읽거나 새 대화를 시작합니다.

출처: CLI commands ↗

/learn [instruction]

세션 중의 피드백·수정 사항을 영구 Rule이나 Skill로 바꿉니다. 검토 가능한 제안 형태로 만들어집니다.

출처: /learn ↗

플러그인으로 스킬 설치

agy plugin list [--json]
agy plugin install <plugin-name>
agy plugin install https://github.com/<owner>/<repo>
agy plugin install ./my-skills-plugin

기본 마켓플레이스는 @antigravity-plugins-official입니다. TUI에서는 /plugin(별칭 /plugins)으로 관리합니다.

출처: Plugins ↗

2. 핵심 워크플로 명령

공식 문서의 "Slash commands overview"에 실린 공개 워크플로 명령입니다. App과 CLI에서 동일하게 동작합니다.

/boost Reasoning유료

멀티 에이전트 심층 추론(Orchestrator → DeepCoder/DeepInvestigator → 작업자). 복잡한 버그·경쟁 상태·알고리즘에 적합. 수 초~수 시간.

/teamwork Reasoning유료

협업 에이전트 팀으로 저장소 규모 마이그레이션·시뮬레이션·연구를 수행. 수 시간~수 일. 일부 환경에선 /teamwork-preview로 표시

/goal Reasoning전 플랜

목표 달성이 검증될 때까지 중간 멈춤 없이 자율 실행. 수 분~수 시간.

출처: /goal ↗

/plan Planning전 플랜

코드를 조사하고 요구사항을 인터뷰한 뒤 검토 가능한 구현 계획 아티팩트를 작성.

/grill-me Planning전 플랜

작업 전에 한 번에 한 질문씩, 추천 답과 함께 인터뷰해 설계 세부와 엣지 케이스를 맞춤.

출처: /grill-me ↗

/learn Customization전 플랜

세션 피드백을 영구 Rule·Skill로 정리.

출처: /learn ↗

/plugin Customization전 플랜

플러그인 관리자를 열거나 플러그인을 설치·관리·생성.

/schedule Automation전 플랜

지시를 일회성 타이머나 반복 cron으로 예약해 에이전트를 깨움.

출처: /schedule ↗

/browser Tools전 플랜

샌드박스 브라우저 서브에이전트로 웹 조사·UI 점검·브라우저 디버깅.

출처: /browser ↗

/btw Tools전 플랜

작업을 멈추지 않고 백그라운드에서 짧은 곁가지 질문.

/generative_ui ToolsApp 전용

다이어그램·차트 등 인터랙티브 위젯을 HTML 아티팩트로 생성. CLI에서는 사용할 수 없음.

출처: Slash commands overview ↗

3. CLI 전체 슬래시 명령

공식 "CLI commands" 레퍼런스의 TUI 슬래시 명령 전체 목록입니다. 프롬프트에서 /를 입력하면 자동완성 메뉴가 열립니다.

행을 클릭하면 자세한 설명과 사용 예, 공식 문서 링크가 펼쳐집니다.

명령분류별칭설명
/add-dir <path>Utilities워크스페이스에 디렉터리 추가
/agentsTools & Tasks에이전트 관리자: 커스텀 에이전트 전환, 서브에이전트 모니터링
/artifactTools & Tasks아티팩트 검토 패널 열기
/boost <task>Reasoning온디맨드 멀티 에이전트 심층 추론
/browser <task>Tools & Tasks브라우저 서브에이전트에 웹 탐색·UI 검증 위임
/btw <query>Utilities대화를 끊지 않고 백그라운드 곁가지 질문
/changelogUtilities릴리스 노트 뷰어
/clearUtilities/new터미널 정리와 대화 컨텍스트 초기화
/codesearch <query>Utilities/cs, /search워크스페이스 코드 검색 패널
/configConfigurations/settings설정 편집기
/contextUtilities컨텍스트 사용량 시각화
/copy [n|btw]Utilities마지막·n번째 응답 또는 최근 /btw 답변 복사
/creditsAccount남은 크레딧과 구매 링크
/diffUtilities변경·턴·커밋 diff 뷰어
/effort [level]Configurations모델 추론 강도 설정(low~max)
/exitCore/quitTUI 종료
/feedbackUtilities피드백 제출
/forkConversations/branch현재 대화를 새 병렬 세션으로 복제
/goal <objective>Reasoning목표 완료가 검증될 때까지 자율 실행
/grill-me [task]Planning작업 전 한 질문씩 추천 답과 함께 인터뷰
/helpUtilities명령·단축키 도움말
/hooksTools & Tasks활성 스크립트 훅 탐색
/keybindingsConfigurations단축키 편집기
/learn [instruction]Tools & Tasks세션 수정 사항을 Rule·Skill로 저장(검토 제안)
/logoutAccount로그아웃과 인증 토큰 삭제
/mcpTools & TasksMCP 서버 관리자
/modelConfigurations기본 모델 선택. /model <model> <prompt>로 1회만 다른 모델 사용
/open <path>Utilities경로를 기본 에디터로 열기
/permissionsConfigurations도구 권한 관리자
/plan [task]Planning코드 조사·요구사항 정리 후 구현 계획 작성
/pluginTools & Tasks/plugins플러그인 관리자, install·uninstall·enable·disable·list
/rename <name>Conversations세션 이름 변경
/remote-control [on/off]Utilities원격 제어 켜기·끄기
/resumeConversations/switch, /conversation이전 대화 선택·불러오기
/rewindConversations/undo이전 메시지 시점으로 되돌리기
/schedule <when> <task>Tools & Tasks일회성 타이머·반복 cron 예약
/skillsTools & Tasks로드된 스킬 탐색, /skills reload로 다시 읽기
/statuslineConfigurations상태 표시줄 사용자화
/tasksTools & Tasks백그라운드 셸 작업 로그 모니터링
/teamwork <task>Reasoning장기 프로젝트용 멀티 에이전트 팀(유료)
/title [on/off]Configurations터미널 창 제목 갱신 설정
/usageUtilities/quota모델 할당량 사용량
/voiceUtilities음성 대화(/voice live)·받아쓰기(/voice dictate)

여기에 더해, 설치된 스킬마다 /<skill-name> 명령이 자동으로 추가됩니다.
